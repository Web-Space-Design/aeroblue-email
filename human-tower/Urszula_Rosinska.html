📋 Jak zainstalować tę stopkę w swojej poczcie
Krok 1. Zaznacz całą stopkę poniżej (od „Pozdrawiam | Best regards" do końca klauzuli RODO/GDPR) i skopiuj (Cmd+C / Ctrl+C).
Krok 2. Wklej w ustawieniach podpisu w swojej poczcie:
Gmail (przeglądarka): ⚙️ Ustawienia → Zobacz wszystkie ustawienia → zakładka Ogólne → sekcja Podpis → Utwórz nowy → wklej (Cmd+V / Ctrl+V) → Zapisz zmiany.
Apple Mail (Mac): Mail → Ustawienia → zakładka Podpisy → wybierz konto → + → wklej. Ważne: odznacz „Always match my default message font".
Outlook (desktop): Plik → Opcje → Poczta → Podpisy → Nowy → wklej → OK. W Wybierz domyślny podpis przypisz do nowych wiadomości i odpowiedzi.
Outlook 365 / web: ⚙️ Ustawienia → Poczta → Redagowanie i odpowiadanie → wklej w polu podpisu → Zapisz.
🛠️ Metoda alternatywna — wklejanie kodu HTML (dla zaawansowanych):
Jeśli kopiowanie z przeglądarki gubi formatowanie (np. w Outlook desktop), użyj surowego kodu HTML:
1. Kliknij prawym przyciskiem na ten plik .html w Finderze/Eksploratorze → Otwórz za pomocą → Notatnik (Windows) lub TextEdit (Mac, w trybie zwykłego tekstu) lub VS Code / Sublime / dowolny edytor tekstu.
2. Zaznacz cały kod między znacznikami ▼▼▼ POCZĄTEK STOPKI ▼▼▼ a ▲▲▲ KONIEC STOPKI ▲▲▲ (znajdź Cmd+F / Ctrl+F).
3. Skopiuj zaznaczony kod (Cmd+C / Ctrl+C).
4. Wklej do swojego klienta poczty:
• Outlook desktop (Windows): najprościej — skopiuj cały plik .html do folderu %appdata%\Microsoft\Signatures\ i nadaj mu sensowną nazwę (np. Human-Tower.html). Outlook automatycznie wykryje go jako podpis.
• Apple Mail: przeciągnij plik HTML do okna ustawień podpisu lub zastąp plik podpisu w ~/Library/Mail/V*/MailData/Signatures/.
• Webmail z trybem HTML (np. niektóre wersje Roundcube, Zimbra, Thunderbird): w ustawieniach podpisu przełącz na tryb „HTML / źródło" i wklej kod.
💡 Wskazówka: Jeśli logo lub ikony się nie wyświetlają — odbiorca prawdopodobnie ma zablokowane pobieranie obrazków. Po pierwszym kliknięciu „Pokaż obrazy" wszystko działa już automatycznie.
